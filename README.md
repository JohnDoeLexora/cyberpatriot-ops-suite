# CyberPatriot Ops Suite

Split-pane competition hardening dashboard for CyberPatriot teams.

**Public repo (share with team):** https://github.com/JohnDoeLexora/cyberpatriot-ops-suite

## Vision

Cursor-style multi-pane workspace: dock ops into several live panels, run many hardening checks/actions at once, hover rows for contextual actions (disable user, flag suspicious, open details).

- **Kosher / competition-legal only** — defensive hardening & auditing on authorized competition images
- **Maximalist within the rules** — automate everything CP allows; creative edge-case ops that stay inside policy
- **Cross-platform engines** — Windows + Linux scripts; **demo/mock mode** so the UI works on macOS without a competition VM
- **Visually sharp** — dense but readable; every button does something (real or mock)

## Status

Scaffolding in progress via Grok Build. Not competition-ready tonight — foundation first.
